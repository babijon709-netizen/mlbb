# Cyber Terminal Overlay GUI (C++ / Android Root)

Проект графического интерфейса (оверлея) для Android с root-правами на C++, стилизованного под киберпанк-терминал PowerShell из референса (`Terminal.jpeg`), с макетом игрового чит-меню (**без функционала / no-op mockups**) для Mobile Legends Bang Bang и других игр.

Оверлей запускается как **самораспаковывающийся `.sh` бинарник** (self-extracting shell asset) через root (`su`), прикрепляется к системному композитору SurfaceFlinger через `libgui.so` и считывает касания через Linux `/dev/input/` (evdev) без блокировки касаний в самой игре.

## 🎮 Вкладки Чит-меню (Макет / Без функционала)

В верхнюю панель интегрированы вкладки, оформленные в том же терминальном моноширинном стиле:

1. **`pwsh` (Терминал / Референс)**:
   - Точное воссоздание референса с ASCII-артом, шкалами железа и интерактивной командной строкой.
2. **`Visuals` (ESP / Radar)**:
   - Переключатели: Master ESP, 2D Box, Skeleton Bones, Snaplines (линии привязки), Health/Shield Bars, Hero Name & Distance.
   - Слайдер дистанции прорисовки (50м – 500м).
   - Круговой радар 360° с отображением меток союзников и противников в реальном времени.
3. **`Combat` (Aim Assist)**:
   - Переключатели: Master Aim, отрисовка круга FOV, упреждение движения (Prediction), проверка видимости (Visible Check).
   - Слайдер радиуса круга FOV (20° – 180°).
   - Слайдер плавности наведения (Smoothness).
   - Выбор приоритета: наименьшее HP%, ближайшая дистанция, ближе к прицелу.
   - Выбор кости: Head / Neck / Chest / Pelvis.
4. **`Misc` (Твики игры)**:
   - Слайдер высоты камеры Drone View (1.0x – 5.0x).
   - Переключатель разблокировки 120 FPS.
   - Отображение кулдаунов способностей врагов.
   - Streamer Mode (сокрытие оверлея при записи экрана через `SetTrustedOverlay` и `eSkipScreenshot`).
   - Журнал событий оверлея (Event History).
5. **`Settings` (Настройки оверлея)**:
   - Регулировка прозрачности окна (Opacity 40% – 100%).
   - Регулировка масштаба интерфейса (Scale 0.6x – 1.4x).
   - **Bubble Mode**: сворачивание оверлея в компактный плавающий светящийся кружок `>_` (чтобы не мешать обзору в игре). Повторный тап мгновенно разворачивает полное меню!
   - Кнопка центрирования и кнопка полного закрытия.

## 🚀 Как запустить на телефоне с Root-правами

### Способ 1: Сборка и запуск прямо на телефоне через Termux (ПК не нужен!)

1. Установите [Termux](https://github.com/termux/termux-app/releases) на телефон с root-правами.
2. Откройте Termux и установите компилятор:
   ```bash
   pkg update -y
   pkg install -y clang make binutils
   ```
3. Склонируйте или скопируйте эту папку в Termux:
   ```bash
   cd ~
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> mlbb
   cd mlbb
   ```
4. Запустите скрипт сборки:
   ```bash
   bash tools/build_termux.sh
   ```
5. Запустите готовый оверлей от имени суперпользователя:
   ```bash
   su -c "sh dist/cyber_overlay.sh"
   ```

---

### Способ 2: Сборка на ПК через Android NDK и запуск по ADB

1. На компьютере установите Android NDK (рекомендуется r25c – r28) и настройте переменную окружения:
   ```bash
   export ANDROID_NDK_HOME=/path/to/android-ndk
   ```
2. Соберите бинарник и упакуйте в `.sh`:
   ```bash
   ./tools/build_android.sh
   ```
3. Подключите телефон по USB с включенной отладкой по ADB и запустите:
   ```bash
   ./tools/deploy.sh
   ```
   Либо вручную:
   ```bash
   adb push dist/cyber_overlay.sh /data/local/tmp/
   adb shell "su -c 'sh /data/local/tmp/cyber_overlay.sh'"
   ```

## ⚙️ Как устроен самораспаковывающийся `.sh` бинарник

Файл `cyber_overlay.sh` представляет собой гибридный исполняемый файл:
1. В начале файла расположен шелл-скрипт под `/system/bin/sh`.
2. После специального разделителя `__PAYLOAD_BELOW__` следует сжатый с максимальным сжатием (`gzip -9`) бинарник ARM64 ELF.
3. При запуске:
   - Скрипт проверяет наличие root (`id -u == 0`).
   - Находит номер строки разделителя с помощью `awk`.
   - Потоково распаковывает payload через `tail + gzip -dc` во временный файл `/data/local/tmp/.cyber_overlay_$$`.
   - Устанавливает права `chmod 700` и запускает его.
   - Обработчик `trap cleanup EXIT INT TERM` гарантирует, что при закрытии меню или нажатии `Ctrl+C` временный бинарник моментально удаляется, не оставляя мусора в системе.

## 🌐 Интерактивное Live Preview в браузере

Прямо в песочнице запущен сервер превью на порту `3000`. В окне Live Preview вы можете:
- Перетаскивать окно мышью или тачем за заголовок.
- Сворачивать окно в плавающий кружок `>_` (Bubble Mode) и разворачивать обратно.
- Кликать по всем вкладкам (`pwsh`, `Visuals`, `Combat`, `Misc`, `Settings`).
- Включать/выключать переключатели ESP (при включении над персонажами на фоне арены появляются 2D-боксы и линии).
- Изменять FOV, прозрачность и масштаб.
- Вводить команды в консоль `PS C:\Users\Vanil>` (`help`, `status`, `esp on`, `clear`).
